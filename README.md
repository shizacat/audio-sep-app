# AudioSep Application

Настольное приложение на Python и Qt: открывает запись и отделяет звук по текстовому описанию. Само разделение делает [AudioSep](https://github.com/Audio-AGI/AudioSep) — модель в этот репозиторий не входит.

## Стек

Python 3.12, PySide6. AudioSep подключается из внешнего каталога, путь задаётся в локальном `config.toml`.
