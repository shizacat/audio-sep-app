## [Unreleased]

### Изменено

- Текст под галкой занимает свою высоту и не наезжает на соседние элементы.

- Минимальная версия Python — 3.12.
- Сборка пакета идёт через Hatchling.
- Версия пакета читается из `__version__` в `src/audiosep_app/__init__.py`.
- Файл настроек из приложения убран: его формат ещё не выбран.
- Поддерживаемые форматы аудио заданы одним требованием; в остальных местах — «аудиофайл».
- Зависимости объявлены в `pyproject.toml` и ставятся uv в `.venv` на Python 3.12. `uv.lock` в репозиторий не входит. Пакет приложения собирает PyInstaller для Linux, macOS и Windows.
- Интерфейс — Qt 6 через PySide6, и PyInstaller собирает такой пакет.
- Проект самодостаточный: без каталогов и окружений вне репозитория. Способ включить код AudioSep решается позже.

### Добавлено

- Стартовое окно приложения. Запуск: `uv run audiosep-app`.
- Аргумент `--log-level` задаёт уровень логирования.
- Базовый интерфейс: аудиофайл, звук для отделения и сохранение результата.
- Поле звука многострочное. Файл результата заполняется после отделения.
- Окно отделяет звук в фоне через ONNX-модели. Аудиофайл читается и сохраняется. При разработке модели лежат в `local/`, у собранного приложения — в каталоге `models` рядом с исполняемым файлом.
- Аргументы `--separator` и `--clap` задают пути к моделям, отличные от путей по умолчанию.
- Если при запуске файл модели не найден, показывается стандартное окно ошибки. После OK приложение закрывается.
- Галка «Убрать отделённый звук из оригинала» сохраняет рядом с исходником две дорожки: `_separated` и `_without`. Имена файлов не спрашиваются. Под галкой всегда виден текст, что делает вычитание.
- Пока идёт отделение, выбор файла, текст запроса, галка, кнопка «Отделить» и «Открыть папку» заблокированы. После завершения они снова доступны.
- Кнопка «Открыть папку» открывает каталог, в котором лежат сохранённые результаты.
- Отдельная подзадача `script/`: экспорт сети разделения и текстовой ветки CLAP в ONNX окружением соседнего AudioSplit.
- `audiosep_app.infer` — библиотека прогона ONNX-моделей для приложения, без командной строки.
- Каркас репозитория: пакет `src/audiosep_app` и тесты.
- Требования к разработке в `docs/development.md`.
- Правила для агентов в `.cursor/rules/`, каждое правило в своём файле.
- Обязательный changelog для дальнейших изменений.
