# Требования к разработке

## Цель

Приложение открывает аудиозапись, принимает текстовое описание звука и сохраняет отделённый результат. Разделение выполняет AudioSep. Этот репозиторий отвечает за окно, конфигурацию, фоновый запуск и показ ошибок.

## Стек

- Python 3.12+.
- PySide6. Другие биндинги Qt не используются.
- Тесты — pytest. Стиль — Ruff.
- AudioSep берётся из внешнего каталога (клон [Audio-AGI/AudioSep](https://github.com/Audio-AGI/AudioSep)). Его код и веса в этот репозиторий не копируются.

Локальная разработка идёт в окружении AudioSep (`environment.yml` из того клона) с дополнительно установленным PySide6. Зависимости окна перечислены в `pyproject.toml`. Зависимости модели остаются в окружении AudioSep.

## Конфигурация

Рабочий файл — `config.toml` в корне репозитория. Образец — `contribute/config.example.toml`. В git попадает только образец.

| Поле | Смысл |
| --- | --- |
| `audiosep_root` | Каталог клона AudioSep |
| `checkpoint` | Файл весов `.ckpt` |
| `config_yaml` | YAML модели. Пустое значение — `config/audiosep_base.yaml` внутри `audiosep_root` |
| `device` | `auto`, `cpu` или `cuda`. `auto` выбирает `cuda`, если он доступен, иначе `cpu` |

## Поддерживаемые форматы

Приложение открывает и сохраняет аудиофайлы MP3, WAV и OGG. Формат задаёт расширение.

Модель AudioSep принимает и отдаёт моно WAV 32 кГц. Адаптер перекодирует аудиофайл пользователя в этот вид и результат обратно в аудиофайл.

Это единственное место, где перечислены форматы. В остальных требованиях достаточно слова «аудиофайл».

## Поведение первой версии

1. Пользователь указывает аудиофайл и текстовый запрос.
2. Разделение идёт в фоне, окно остаётся отзывчивым.
3. Результат можно сохранить в аудиофайл.
4. Ошибка конфигурации, загрузки модели или разделения показывается текстом в окне.

Запрос передаётся в AudioSep как есть. Модель обучена на описаниях на английском.

## Границы модулей

- `src/audiosep_app/ui/` — виджеты и сигналы. Этот пакет не импортирует PyTorch и AudioSep.
- `src/audiosep_app/separation/` — чтение конфигурации и вызов AudioSep. Этот пакет не импортирует PySide6.
- Окно просит разделить файл, адаптер возвращает путь к аудиофайлу или ошибку с понятным текстом.

Вызов AudioSep:

- загрузка — `build_audiosep(config_yaml, checkpoint_path, device)`;
- разделение — `separate_audio(model, audio_file, text, output_file, device, use_chunk=...)`.

Модель загружается один раз и переиспользуется. Для длинных записей адаптер включает `use_chunk=True`.

## Проверки

- Тесты подменяют адаптер и не скачивают веса.
- Публичные функции аннотированы типами.
- Перед завершением задачи, которая меняет поведение или структуру, в `CHANGELOG.md` есть запись в секции `[Unreleased]`.

Команды:

```shell
pip install -e ".[dev]"
ruff check src tests
pytest
```
